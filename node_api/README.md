# Boilerplate Node.js

Este es un boilerplate básico para iniciar un proyecto con Node.js.

## Instalación

```bash
npm install
```

## Uso

### Modo desarrollo (con recarga automática):
```bash
npm run dev
```

### Modo producción:
```bash
npm start
```

El servidor se levantará en [http://localhost:3000](http://localhost:3000)
